## Trạng thái

| Công việc | Trạng thái và bằng chứng |
|---|---|
| Code, 5 cấu hình và báo cáo | Có trong ZIP gốc: src, results, report |
| Notebook phần 1–4 | Người dùng đã báo chạy xong trước đó; output chưa có trong notebook ZIP |
| Bộ docs | Đã bổ sung trong gói này |
| Hướng dẫn cũ không thống nhất | Đã sửa README, BAT_DAU_O_DAY và hướng dẫn nộp |
| Tên, MSSV, lớp, giảng viên | Chờ nhóm điền trong docs và báo cáo |
| Phân công và lịch sử thực tế | Chờ nhóm xác nhận; không tự đặt tên, ngày làm hoặc tỷ lệ |
| Push và merge GitHub | Chưa thực hiện bởi lần đóng gói này |
| Demo suy luận ảnh mới | Chưa có; chỉ bổ sung nếu yêu cầu lớp |
| Tên chính xác file tiến độ | Xác nhận lại ảnh bảng với cô |

## Kế hoạch hoàn tất

1. Điền thông tin và xác nhận phân công.
2. Kiểm tra tên các file theo yêu cầu chính thức.
3. Đưa tài liệu lên nhánh riêng, kiểm tra diff, mở PR vào main.
4. Sau khi merge, chạy lại notebook phần 1–4 từ link Colab, lưu output nếu yêu cầu.
5. Tập thuyết trình và kiểm tra hạn/hình thức nộp chính thức.
